## Task 1: Data Cleaning

**Objective:** Clean and prepare raw data for further analysis.

**Activities:**
- Loaded and inspected the original dataset.
- Identified missing values and data quality issues.
- Cleaned and organized the data.
- Prepared the cleaned dataset for further analysis.

**Tools Used:**
- Python
- Pandas

**Folder:** `CodeOrbit_DataCleaning/`

## Task 2: Sales Data Analysis

**Objective:** Analyze sales data to understand sales performance and regional trends.

**Activities:**
- Processed sales data using Python.
- Analyzed sales performance across different regions.
- Generated regional sales results.
- Created a chart to visualize sales by region.

**Tools Used:**
- Python
- Pandas
- Matplotlib

**Files:**
- `sales_by_region.csv` — Regional sales analysis results.
- `sales_by_region.png` — Visualization of sales by region.

**Folder:** `CodeOrbit_SalesAnalysis/`
